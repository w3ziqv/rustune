# Clean TUI validation

The Search and Settings screenshots in the README were captured from a real Kitty window during native playback. The smooth artwork check observed 1,568 Kitty image placeholders on the Now Playing screen. The 15-second run used the balanced profile and the system FFmpeg build.

| Smooth artwork during playback | Measurement |
|---|---:|
| Mean native PSS / RSS | 146.52 / 181.04 MiB |
| Peak native PSS / RSS | 146.57 / 181.05 MiB |
| Native CPU, one core | 2.35% |
| Kitty peak PSS (whole terminal process) | 289.91 MiB |
| Kitty CPU, one core | 0.43% |

Native totals include the service, TUI and audio helper with its CDM. Kitty was measured separately. This short run predates the final navigation fixes. The terminal figure includes its normal window and renderer, so it cannot by itself establish the incremental cost of smooth artwork.

Run the live measurements with a test environment containing pyte, two adjacent release executables and the local playback prerequisites described in the README. Each invocation creates its own temporary configuration, service and queue.

```sh
python scripts/measure-idle.py target/release/rustune
python scripts/measure-clean-tui.py --live --cycle --seconds 30 target/release/rustune pixel.json
python scripts/measure-clean-tui.py --live --style smooth --terminal kitty target/release/rustune smooth.json
python scripts/measure-clean-tui.py --live --style off target/release/rustune off.json
python scripts/measure-clean-tui.py --live --cycle --seconds 3600 target/release/rustune hour.json
```

The [individual runs](2026-11-17-clean-tui-runs.json) include executable hashes, CPU and peak renderer PSS for smooth artwork.

The November 17 release binary completed a subscribed song from zero to 359.75 seconds. The helper processed 15,493 encrypted packets, decoded 15,493 frames and reported 31,492,801 nonzero output samples. The test verified pause, resume, seek, volume, worker replacement and cleanup. The executable SHA-256 was `c1a32986bc37990a1d4ade819957b2600e8c59afc1235c8065b4bddfc12f32fd`.

The isolated PTY checks covered the seven destinations, public catalog searches, dedicated lyrics, settings, queue edits, mouse controls and terminal resizing. SIGTERM and SIGHUP restored the original terminal settings and reaped the service started by the TUI.

Formatting, Clippy with warnings denied, the 185 offline tests and the release build passed. Public LRCLIB and artwork checks passed separately.
